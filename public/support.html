SourceNerve Support

For product questions, reproducible bugs, OAuth connection problems, or repository workflow issues, open an issue in the public SourceNerve repository:

github.com/khovan123/SourceNerve/issues

Include the SourceNerve version, the tool name, expected behavior, and sanitized error output where useful.

Do not post secrets

Never include OAuth access or refresh tokens, Auth0 Management API tokens, GitHub or GitLab tokens, webhook secrets, private keys, repository credentials, or unredacted confidential source code in a public issue.

Security reports

For a suspected security vulnerability, use the repository's GitHub security reporting facilities when available rather than publishing exploit details in a normal issue. If private reporting is not available, open a minimal issue requesting a private contact path without disclosing the vulnerability details.

Data requests

For access or deletion assistance related to a SourceNerve deployment, identify the deployment and authorized workspace without posting credentials. Persistent data is controlled by the operator of that SourceNerve deployment.

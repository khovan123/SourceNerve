SourceNerve

Persistent repository intelligence and guarded Git and repository-provider workflows for ChatGPT and Codex.

SourceNerve can inspect authorized repositories, build bounded code context, trace symbols and dependencies, and carry approved changes through guarded branch, patch, review, commit, push, pull-request, and merge workflows.

The public MCP endpoint is https://sourcenerve.fogewise.io.vn/mcp. Access is authenticated with OAuth and limited by server-side workspace grants.
